ARCHITECTURE CHANGES:
====================

1. Dynamic API Response Enrichment
   - `/skill-graph/{roadmap_id}/dynamic-status` now includes `prerequisites`
   - Eliminates separate prerequisite lookup call from frontend
   - Enables rich lock-reason UI without cascading queries
   - Zero additional backend load (uses existing Q3 data)

2. User Level Context in UI
   - RoadmapDetailPage derives user level from global_elo_rating
   - Difficulty badges become "level aware": show "Requires Level N" only when relevant
   - Reduces cognitive load for users by explaining primary blocker
   - Example: "Locked — 2 prerequisites remaining" vs "Requires Level 4 — Practitioner"

3. Frontend Sorting & Display Order
   - New `roadmapUtils.sortDynamicCourses()` standardizes course ordering
   - Applied in RoadmapDetailPage for consistent render order
   - Simplifies component logic (sorting happens once, not per-render)

4. Test Coverage
   - Pure logic tests via vitest (no React dependencies)
   - Fast execution, deterministic, tooling-agnostic
   - 50 total unit tests for utility functions
